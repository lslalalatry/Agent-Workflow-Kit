# 权限模型与凭据安全契约（Security & Auth）

> 本文档定义系统访问控制、数据隔离、密钥保管与高风险操作审批边界。所有未明确放行的接口与操作默认拒绝（Fail-Closed）。

---

## 1. 角色与权限矩阵（RBAC）

| 角色标识 | 适用对象 | 核心权限范围 | 数据可见范围（行级/租户级隔离） | 明确禁止的操作 |
| :--- | :--- | :--- | :--- | :--- |
| `admin` | 系统管理员 | 全局配置、成员管理、人工覆盖、发布与回滚 | 全量可见 | 禁止绕过审计日志直改生产账本 |
| `operator` | 业务运营/执行者 | 日常查询、任务触发、人工打标/复核 | 仅所属工作区或已分配数据 | 禁止修改系统配置、删除历史归档 |
| `viewer` | 只读访客/观察者 | 查看已发布看板与只读导出 | 仅脱敏或已发布范围 | 禁止触发任何写操作或付费任务 |

---

## 2. 接口鉴权与高危操作防线

1. **默认鉴权原则**：除显式声明的 `/api/health` 与 `/login` 外，所有业务接口与静态数据下载必须校验有效会话或签名 Token，匿名访问统一返回 `401 / 302`。
2. **跨成员资源隔离**：单资源详情、编辑、删除接口必须校验资源归属权（`owner_id` / `workspace_id`），禁止仅凭自增 ID 或 UUID 越权读取他人草稿。
3. **高影响动作二次边界**：涉及**付费外呼、批量删除、生产覆盖、正式发布**的操作，必须在后端开关与前端显式确认双重受控；默认测试环境关闭真实付费开关。

---

## 3. 凭据、密钥与敏感数据保管规则

| 敏感资产类型 | 允许存放位置 | 严禁出现的区域 | 轮换与泄露处置 |
| :--- | :--- | :--- | :--- |
| **数据库/对象存储密钥** | 宿主机受限 `.env` / Secrets（`0600` 权限） | Git 仓库、前端构建产物、日志、报错堆栈 | 泄露即刻吊销重建，严禁仅改代码注释 |
| **第三方 API Key / OAuth Token** | 服务端环境变量或加密凭据库 | URL Query 参数、前端本地存储、共享文档 | 未知主机或未校验域名禁止发送凭据 |
| **用户个人 Cookie / 会话** | 仅允许本人受控使用 | 后台全天候无人值守批处理爬虫 | 不得借用个人账号代跑公共队列 |
