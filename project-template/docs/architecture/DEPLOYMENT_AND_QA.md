# 开发环境、QA 部署与回滚验收规范（Deployment & QA）

> 本文档定义本地、测试（QA）与生产三套环境的隔离边界、环境变量契约、发布检查及回滚机制。所有部署与备份必须经过真实演练验证。

---

## 1. 环境矩阵与隔离红线

| 环境 | 部署方式 | 数据与媒体来源 | 外部付费 / 写入开关 | 唯一访问入口 |
| :--- | :--- | :--- | :--- | :--- |
| **本地开发 (`local`)** | 本地进程 / 容器 | 脱敏微型夹具或只读快照 | **强制关闭**（Mock 或 Dry-run） | `http://127.0.0.1:<port>` |
| **QA / 隔离验收 (`staging`)** | 独立容器 + 独立库 | 脱敏全量副本或受控测试集 | 默认关闭，按批显式授权开启 | 内网或隧道访问 |
| **正式生产 (`prod`)** | 受管 Compose / 容器 | 正式集中数据库 + 正式对象存储 | 正式开启（受配额熔断保护） | `https://<domain-or-gateway>` |

---

## 2. 环境变量契约（与 `.env.example` 对齐）

| 变量名 | 必填 | 作用域 | 说明（不含真实密钥） |
| :--- | :---: | :--- | :--- |
| `APP_ENV` | 是 | 全部 | `local \| staging \| prod` |
| `DATABASE_URL` | 是 | 后端 / Worker | 指向集中关系型数据库对应账号与 Schema |
| `OBJECT_STORAGE_ENDPOINT` | 按需 | 后端 / Worker | 对象存储服务地址与 Bucket 名 |
| `PAID_EXECUTION_ENABLED` | 按需 | Worker | 外部按次计费操作总开关（测试默认 `false`） |

---

## 3. 发布前检查、备份还原与一键回滚

1. **发布前门禁**：工作树干净、通过全量测试与 `verify_guardrails.py`、`code_review.py` 登记匹配版本。
2. **部署幂等与留旧指针**：每次升级应用镜像与数据结构前，先保留上一版可运行镜像标签与逻辑/物理快照指针（如 `app-previous` / `data-previous`）。
3. **备份真实可用性铁律**：**备份任务返回退出码 `0` 不代表备份可用**；必须在无业务写入的隔离环境中定期执行实际 `restore` 还原，核对表数、关键行数与媒体引用完整性。

   - 数据回滚：`<填写数据恢复或指针切回命令及前置停写步骤>`
